# Instruções permanentes do MK9 DATE

## Publicações e Fast Release
- Antes de qualquer merge, publicação, deploy ou operação que possa alterar produção, Guts, Levi e Copilot devem ler a versão canônica docs/releases/FAST_RELEASE_V1.md no repositório e classificar a missão como Fast Release Light, Standard ou Database.
- A leitura é obrigatória a cada missão de publicação; este arquivo e docs/AGENTS.md não substituem o procedimento canônico.
- Produção e deploy exigem autorização administrativa explícita e gates aprovados. Não executar migrations, alterar dados remotos, contornar proteção de branch, usar force push, acionar GitHub Actions ou gerar custos sem autorização específica.
- Trabalhar em branch isolada, preservar mudanças existentes e reportar evidências, limitações e GO/NO-GO.
