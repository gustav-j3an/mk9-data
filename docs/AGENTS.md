# Instruções para a documentação de releases

- docs/releases/FAST_RELEASE_V1.md é o procedimento canônico do MK9 DATE. Guts, Levi e Copilot devem consultá-lo antes de qualquer publicação, merge ou deploy.
- Classificar cada release como Fast Release Light, Standard ou Database segundo o procedimento canônico.
- Preservar histórico e arquivos existentes; não converter documentação de preflight em pacote executável nem afirmar resultados sem evidência.
- Uma documentação ou aprovação anterior não substitui autorização separada para produção e deploy.
